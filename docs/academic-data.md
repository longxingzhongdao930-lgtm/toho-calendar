# 2026年度学年暦の抽出記録

一次資料はユーザー提供の4枚のスクリーンショットです。前期2枚・後期2枚はそれぞれ同じページの上下を写しています。画像上の「2026.4.1」表記を参照し、2026年4月〜2027年3月のデータを `lib/academic.ts` に登録しました。スクリーンショット・画像由来の個人情報はリポジトリにも配信物にも含めません。

## 読み取りの範囲

- 日付と予定名を画像上で確認できた予定だけ `verification: official`（公式資料確認済み）とします。時刻、会場、個別の履修条件、後日の変更までは確認済みという意味ではありません。
- 細字の名称・対象・期間が判読できない項目は `unverified`（要確認）。本文が読めない色帯も、位置が判別できた日付の「学年暦の細字記載」として残します。位置の日付は、本文に書かれた対象期間の確定を意味しません。
- 白い空欄から休日や休講を推定しません。祝日だけの記載からキャンパスクローズとも推定しません。
- 「学科目補講可能日」を「すべての通常授業・レッスンが休み」とは扱いません。「予定」「未定」の原文は残します。
- 授業・レッスン回数は判読できた42日分のみ数値を転記。それ以外は前期4/1〜7/18、後期9/7〜1/23の月〜土の欄を「回数・通常授業の有無は要確認」として表示します。これは授業実施日の自動生成ではありません。数字を連番や週計算で補完していません。
- 回数は資料の曜日別共通欄です。学科目と個別レッスンを独立した2つの実施回数に分解できないため、そのような数値は作っていません。
- 画像の細字は完全には読めていません。全項目を確定したデータではなく、要確認事項を明示した年度カレンダーです。

同一日に祝日、授業、演奏会など複数の記載があれば独立した予定として保持し、日付ごとにまとめて表示します。授業回数と試験・まとめ期間が重なる場合も両方表示し、試験時の履修条件は別途確認できるよう注記します。

## 移行と重複防止

- 公式予定は固定のIDと `academicRevision` で管理。再起動・再読込・同じデータの再移行で増殖しません。
- 旧 `academic-*` の未編集の初期データだけを差し替えます。メモ・会場・タイトル・日付等を編集した旧項目は個人用コピーとして保持し、大学公式の新しい日程を別に登録します。
- 個人が作成した予定を、タイトルが公式予定と同じという理由では削除しません。
- 現行リビジョンのバックアップは公式予定を削除した状態も維持。空のバックアップにも勝手に初期データを補いません。
- 公式予定の「個人用コピーを編集」では元の大学予定を変更せず、編集後のコピーから「公式資料確認済み」を外します。
